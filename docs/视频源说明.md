# 视频源说明

> 本文档说明道路监控视频流的来源、切换方式与扩展方法，以及为什么上海路网功能与视频源是**解耦**的。

---

## 一、结论速览

| 项目 | 状态 |
|------|------|
| **实时视频流** | 使用 **河南高速云视频**（`weixin.hngscloud.com`） |
| **上海视频流** | ❌ 无公开接口，仅保留接入位 |
| **上海路网 / 地图 / 地理编码** | ✅ **完整保留**，与视频源完全解耦 |
| **默认视频源** | `henan` |

---

## 二、为什么视频源是河南，而路网是上海

这是两个**相互独立**的子系统：

```
┌─────────────────────────────┐     ┌──────────────────────────────┐
│   视频源层（可切换）          │     │   地理信息层（保留上海）        │
│                             │     │                              │
│  henan   ✅ 可用（默认）      │     │  上海 16 区行政区划            │
│  shanghai ❌ 仅保留接入位     │     │  内环/中环/外环/延安/南北高架   │
│                             │     │  高德实时路况图层              │
│  services/                  │     │  高德驾车路线规划              │
│    video_source_service.py  │     │                              │
└─────────────────────────────┘     └──────────────────────────────┘
              │                                    │
              └──────────────┬─────────────────────┘
                             ▼
                    检测 / 预警 / 大屏
```

**为什么这样拆分**

1. 上海市交警总队与市交通委**未开放公开的监控视频接口**（公安视频专网与互联网物理隔离）。
2. 河南高速云平台提供了可访问的公开直播流，能够支撑真实视频流的算法验证与演示。
3. 路网拓扑、拥堵计算、绕行推荐等能力**不依赖视频源**，因此完整保留上海数据，避免推倒重来。
4. 未来若获得上海的合法接入渠道，只需新增一个 Provider，**业务层与前端零改动**。

## 四、接口

### 4.1 通用接口（推荐使用）

| 方法 | 路径 | 参数 | 说明 |
|------|------|------|------|
| GET | `/detection/api/video/sources` | — | 列出所有视频源及可用状态 |
| GET | `/detection/api/video/cameras` | `source`, `count`, `exclude` | 检索摄像头列表 |
| GET | `/detection/api/video/stream-url` | `source`, `cameraNum` | 获取 M3U8 直播流地址 |
| GET | `/detection/api/video/snapshot` | `source`, `cameraNum`, `road_id` | 抓帧 + YOLO 检测 |

`source` 省略时使用 `Config.VIDEO_SOURCE`。

### 4.2 兼容别名（历史路径，仍可用）

| 历史路径 | 等价于 |
|----------|--------|
| `/detection/api/hngs-camera-list` | `/detection/api/video/cameras?source=henan` |
| `/detection/api/hngs-camera-url` | `/detection/api/video/stream-url?source=henan` |
| `/detection/api/hngs-camera-snapshot` | `/detection/api/video/snapshot?source=henan` |

> 别名内部同样走适配层，新代码请使用 `/api/video/*`。

### 4.3 上海路网接口（保留，与视频源无关）

| 路径 | 说明 | 位置 |
|------|------|------|
| `/api/amap-route` | 高德驾车路线规划 | `routes/main_routes.py` |
| `/api/amap-geocode` | 高德地理编码（默认 `city=上海`） | `routes/main_routes.py` |
| `/road-network` | 路网地图页面（上海路网 + 实时路况图层） | `routes/main_routes.py` |
| — | 上海路网数据初始化（12 路口 + 26 路段） | `services/road_network_service.py` |

## 五、配置项

全部位于 `config.py`，均可被同名环境变量覆盖。

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `VIDEO_SOURCE` | `henan` | 当前生效的视频源 key |
| `HNGS_API_BASE` | `https://weixin.hngscloud.com` | 河南高速云平台地址 |
| `HNGS_REFERER` | `https://weixin.hngscloud.com/` | 上游校验 Referer，不可省 |
| `HNGS_REQUEST_TIMEOUT` | `10` | 接口请求超时（秒） |
| `HNGS_DEFAULT_CAMERA` | `1324629868805103618` | 默认摄像头编号 |
| `HNGS_VIDEO_TYPE` | `2` | 码流类型（2 = 高清） |
| `HNGS_VIEWPORT` | 河南全省 | 摄像头检索视野范围 |
| `SHANGHAI_VIDEO_ENABLED` | `0` | 上海视频源开关（当前无实现） |
| `FFMPEG_PATH` | 空（自动探测） | ffmpeg 可执行文件路径 |
| `FRAME_CAPTURE_TIMEOUT` | `20` | 抽帧超时（秒） |

**切换视频源示例**

```powershell
$env:VIDEO_SOURCE = "henan"
python app.py
```

## 六、视频流链路

```
河南高速云平台
      │  GET /camera/playUrl  (Referer 校验)
      ▼
  带时效 token 的 m3u8（约数小时有效）
      │
      ├──► 前端 hls.js 播放（多路监控大屏 / 摄像头页面 / 路网页面）
      │
      └──► 后端抽帧（ffmpeg，失败回退 OpenCV）
                 │
                 ▼
            YOLO 检测 → MongoDB 落库 → Redis 缓存 → 前端叠加展示
```

**注意**：m3u8 地址带时效 token，**不可缓存复用**。每次播放或检测都应重新调用 `/api/video/stream-url`。

## 七、扩展新视频源

只需三步，业务层与前端无需改动：

**第 1 步**：在 `services/video_source_service.py` 中继承 `VideoSourceProvider`

```python
class ZhejiangVideoProvider(VideoSourceProvider):
    key = 'zhejiang'
    display_name = '浙江高速云视频'
    region_label = '浙江'

    def is_available(self):
        return True, ''

    def list_cameras(self, count=8, exclude=None):
        # 返回 {'cameras': [...], 'totalAvailable': int, 'totalAll': int}
        ...

    def get_stream_url(self, camera_num):
        # 返回 m3u8 地址
        ...
```

**第 2 步**：注册

```python
_PROVIDER_REGISTRY = {
    HenanVideoProvider.key: HenanVideoProvider,
    ShanghaiVideoProvider.key: ShanghaiVideoProvider,
    ZhejiangVideoProvider.key: ZhejiangVideoProvider,   # 新增
}

_SETTINGS = {
    ...
    ZhejiangVideoProvider.key: {...},                   # 新增
}
```

**第 3 步**：在 `config.py` 中加入对应配置项，并把 `VIDEO_SOURCE` 指过去。

`capture_frame` 已由基类基于 `grab_frame()` 实现，**无需覆写**。

## 八、合规声明

本系统视频数据来源遵循以下边界：

| 允许 | 禁止 |
|------|------|
| ✅ 上游平台**主动公开**并可正常访问的接口 | ❌ 未经授权扫描/破解摄像头 |
| ✅ 公开授权的学术数据集（UA-DETRAC、AI City Challenge 等） | ❌ 使用来源不明的"摄像头 IP 列表" |
| ✅ 自购网络摄像头（RTSP） | ❌ 采集、存储、转发他人视频内容 |

依据：《中华人民共和国刑法》第 285/286 条、《公共安全视频图像信息系统管理条例》（2025-04-01 施行）、《个人信息保护法》《数据安全法》。

上游接口的可用性、服务条款与调用频率限制由**使用方自行确认并遵守**。
